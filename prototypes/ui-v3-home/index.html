场景

四个方案共用的模块约定

  • 模块 = 名称 + 图标 + 桌面摘要（glance）+ 全屏页面。桌面只负责展示摘要和跳转，新功能只需注册一个模块。
  • 返回：模块内点顶部状态栏或在第一页右滑回到桌面；和 v2 详情页“点顶部 / 右滑返回”是同一个手势，只是多了一层。
  • GPIO0 单击仍是熄屏 / 亮屏，不占用作导航。上电默认进桌面；是否“记住上次所在模块”可以后续再定。
  • 目前只有 Sub2API 和系统两个模块；还没实现的模块（计时器等）不显示，也不放占位。
